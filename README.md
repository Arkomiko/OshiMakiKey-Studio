# OshiMakiKey Studio

Portable-программа для настройки китайской макро-клавиатуры на чипе **CH552** (USB `1189:8890`): 6 клавиш (сетка 3×2) и ручка-энкодер.
Каждой клавише и каждому действию ручки (поворот влево, нажатие, поворот вправо) можно назначить:

- **Клавиши** — сочетание или последовательность до 5 нажатий (`Ctrl + C`, затем `Ctrl + V`);
- **Мультимедиа** — громкость, пауза, треки, яркость, калькулятор, проводник, кнопки браузера;
- **Мышь** — щелчок левой/правой/средней кнопкой, колесо (в том числе с Ctrl/Shift/Alt);
- **Система** — запуск программы, сайт, файл/папка, ввод текста, команда cmd, блокировка, выключение экрана, сон, выключение, перезагрузка.

В редакторе у каждого действия есть отметка:

- **✓** — записывается в память клавиатуры и работает даже без программы, на любом компьютере;
- **⚙** — выполняет программа в фоне: устройство отправляет служебную клавишу F13–F24, программа делает остальное.

## Запуск

`OshiMakiKeyStudio.exe` в корне проекта. Нужен .NET 8 Desktop Runtime.

1. Подключите клавиатуру **USB-кабелем**.
2. Запустите `OshiMakiKeyStudio.exe`.
3. Первый раз: **Устройство → Подобрать способ записи…** — мастер сам определит, какой формат понимает ваша плата (см. ниже).
4. Слева щёлкните по клавише или ручке, справа выберите действие.
5. Нажмите **«Записать в устройство»** (F5) и **переподключите кабель** клавиатуры.
6. Проверьте в **«Устройство → Монитор нажатий»** (F8): он показывает, что устройство реально отправляет в компьютер.

Для действий с ⚙ включите **Настройки → Запускать вместе с Windows**: программа будет стартовать свёрнутой в трей.

## Portable

Программа ничего не хранит в профиле Windows. Все данные лежат в папке `user_data` рядом с exe:

```
OshiMakiKeyStudio.exe
user_data/
  settings.json    настройки и профиль
  monitor.log      журнал монитора нажатий и мастера подбора
```

Папку можно переносить целиком — на другой диск, флешку или компьютер. Единственное, что пишется вне её, — запись автозапуска в `HKCU\...\Run`, и только если его включить в настройках.

## Разные прошивки

С одним и тем же USB ID `1189:8890` продаются платы с разными прошивками. Мастер подбора по очереди записывает три варианта, у каждого свои тестовые буквы, и по букве, которую напечатала клавиша 1, понимает, какой сработал:

| Вариант | Кадр | Тестовые буквы (клавиши / ручка) |
|---|---|---|
| Прямой (padclaude) | `03 [кнопка] [мод] 00 [код]` между `03 A1 01` и `03 AA AA` | `abcdef` / `ghi` |
| Официальная программа, «версия 0» | `[кнопка] 01 [кол-во] [номер] [мод] [код]`, после каждой кнопки `AA AA` | `jklmno` / `pqr` |
| ch57x-keyboard-tool (k8890) | `03 FE …`, `03 [кнопка] [слой/тип] …`, `03 AA AA` | `stuvwx` / `yz1` |

Что умеет сама плата, зависит от варианта: прямой хранит одно сочетание клавиш на кнопку, остальное делает программа (⚙); официальный и ch57x сами выполняют клавиши, мультимедиа и мышь. Способ можно выбрать и вручную: **Устройство → Способ записи**.

Что известно о плате:

- она низкоскоростная (пакет 8 байт);
- запись идёт только через interrupt OUT (`WriteFile`), управляющий SET_REPORT прошивка отклоняет (STALL);
- мультимедиа-интерфейс битовый: громкость− = бит 0, громкость+ = 1, без звука = 2, следующий трек = 3, предыдущий = 4, пауза = 5…

## Нужен ли драйвер?

Нет. Устройство — стандартное USB HID-устройство с четырьмя интерфейсами (клавиатура, мышь, мультимедиа и служебный интерфейс для программирования). Windows обслуживает их встроенными драйверами. Программа пишет настройки в служебный интерфейс через стандартный `hid.dll`, без прав администратора и без UsbDk/Zadig.

Роль «драйвера» для действий с ⚙ играет фоновый агент:

```
клавиша на устройстве ──► устройство отправляет служебную клавишу (F13…F24, Shift/Ctrl + F13…)
                                   │
                                   ▼
OshiMakiKey Studio (трей) ── RegisterHotKey перехватывает её ──► мультимедиа / мышь / запуск / текст / …
```

## Сборка

```bash
dotnet build MacroPadStudio
```

Portable-exe (публикация во временную папку, затем exe кладётся в корень проекта):

```bash
dotnet publish MacroPadStudio -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=None -o publish
```

Служебные параметры `OshiMakiKeyStudio.exe`:

- `--selftest отчёт.txt` проверяет все три формата, каталоги, служебные клавиши и сохранение;
- `--probe отчёт.txt` находит устройство, определяет ревизию, открывает служебный интерфейс (настройки не меняет);
- `--monitortest отчёт.txt` проверяет монитор: программно нажимает F24 и сохраняет журнал;
- `--snapshot окно.png --select Key1 --kind System` делает снимок окна;
- `--tray` запускает свёрнутой в трей (так её запускает автозапуск).

## Ограничения

- Настройки нельзя прочитать обратно из устройства: прошивка поддерживает только запись.
- Записывать можно только по USB-кабелю.
- Слои есть только в формате ch57x.
- Номера кнопок ручки для новой ревизии публично не установлены; мастер подбора проверяет и их и пишет результат в журнал.
- Яркость через программу меняется только у встроенного экрана ноутбука (так позволяет Windows).
