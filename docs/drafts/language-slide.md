# Черновик: анимированный слайд выбора языка

Статус: идея, пока не реализуется. Сейчас первый шаг мастера первого запуска — обычные карточки языков.

## Концепция

- На первом слайде мастера по экрану **очень медленно плывут слева направо** надписи «Выберите язык.» на всех языках из папки `language` (каждая строка — свой язык).
- Надписи **разного размера**, на разной высоте и с разной скоростью, чтобы получился спокойный «поток».
- Все надписи и кнопки — с **непрозрачностью 72 %**.
- При наведении мыши на надпись или кнопку её цвет становится **100 %**.
- Щелчок по надписи выбирает соответствующий язык (как карточка сейчас).

## Заметки к реализации

- Текст брать из ключа `setup.language.title` каждого языкового пакета, а не из одного файла: так новые языки появятся на слайде сами.
- Анимацию отключать вместе с будущей настройкой «Анимации темы» (статичная раскладка надписей).
- Перерисовка по таймеру (~30 кадров/с) только пока слайд виден; без постоянной нагрузки на процессор.
